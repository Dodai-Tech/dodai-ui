# dodai-icons

Resolves a typed `IconId` to a drawing in the style of the active Dodai design system. Toolkit-neutral: a `Glyph` can be exported as SVG or a coverage mask, or drawn by an adapter.

Icon artwork for Neo-Brutalism and the shared fallback set is derived from Phosphor Icons (MIT, © Phosphor Icons); see `NOTICE`. It is an internal detail, not exported.
