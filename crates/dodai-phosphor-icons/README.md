# dodai-phosphor-icons

All ~1,500 [Phosphor Icons](https://phosphoricons.com) (MIT) at the `regular` weight, plus each
`-fill` form, as flattened vector data on the Material pack's `0 -960 960 960` grid.

This is the shared icon *vocabulary* of the Dodai design systems: a design that has no icon of
its own for a Phosphor name derives one from here, in its own style (Material draws it as is,
Cyberpunk angularises it). `CATEGORIES` holds Phosphor's own grouping.

Generated by `../dodai-neobrutalism-icons/scripts/generate.nu` (nushell). Artwork © Phosphor Icons, MIT.
