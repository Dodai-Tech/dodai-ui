# dodai-neobrutalism

The **Neo-Brutalism** design system for [Dodai UI](https://github.com/sorinirimies/dodai-ui): thick solid outlines, hard offset shadows that never blur, flat saturated colour blocks on cream paper (or on warm black), heavy type and bouncy motion.

```rust
let all = dodai_neobrutalism::variants(); // 12 themes: 6 accents x light/dark
let t = dodai_neobrutalism::light();
```

Depends only on `dodai-core`. Combine with other design systems through the `dodai` umbrella crate.
